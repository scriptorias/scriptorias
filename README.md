# Scriptorias

*Discover Your Path.* A digital library of ancient religious and historical writings, starting with Christianity.

Static HTML/CSS/JS with no build step. To run it, serve the folder (`python3 -m http.server`) and open `index.html`.

- `index.html`: app shell (sidebar, main, mobile tab bar)
- `app.js`: hash router and views (library, collection page, work overview, paths, search, bookmarks)
- `reader.js`: reusable reading interface (translations, contents, settings, bookmarks, progress, notes, passage references)
- `styles.css`: design tokens and layout (desktop sidebar; phone drawer and tab bar below 820px)
- `data/library.js`: catalog of traditions, collections, works, paths, and work detail (About, Themes, Related)
- `data/didache.js`: sample text, Didache chapters 1–3 in J. B. Lightfoot's 1891 translation (public domain, via Wikisource), generated by `tools/parse_didache.py`
- `data/1-enoch.js`: R. H. Charles' 1912 translation of 1 Enoch, chapters 1–16 (public domain, via Wikisource), parsed into chapters, verses, and poetry lines

Routes: `#/library/christianity`, `#/c/<collection>`, `#/w/<work>` (overview), `#/w/<work>/read/<chapter>/<passage>`, `#/w/<work>/ms/<manuscript>`, `#/path/<id>`, `#/search/<q>`, `#/bookmarks`.

Passage references use the form `work.section.passage` (e.g. `didache.1.7`) and are shared across translations.
